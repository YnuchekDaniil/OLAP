# Паспорт витрины (P02 / зачёт)

ФИО: Янучек Даниил Александрович, Осипчук Артём Вячеславович · Дата: **12.11.2026** · Домен: **Интернет-магазин — Brazilian E-Commerce Dataset by Olist**

## 1. Бизнес-цель витрины (1–2 предложения)

Создать аналитическую витрину для изучения продаж интернет-магазина Olist. Витрина позволит анализировать оборот, количество проданных товарных позиций и распределение продаж по датам, категориям товаров, покупателям и продавцам.

## 2. Grain (одна фраза)

Одна строка факта = одна позиция товара в заказе (один `order_id` и `order_item_id`).

## 3. Fact-таблица(ы)

|Имя|Grain|Примечание|
|---|---|---|
|fact_order_items|Одна товарная позиция в заказе|Содержит сведения о товаре, продавце, заказе, цене и стоимости доставки|

## 4. Меры

|Мера|Тип (sum ok / нет)|Определение|
|---|---|---|
|revenue|sum ok|Оборот — сумма стоимости товаров `SUM(price)` по доставленным заказам|
|freight_total|sum ok|Общая стоимость доставки `SUM(freight_value)`|
|order_items_count|sum ok|Количество товарных позиций — `COUNT(*)`|
|orders_count|нет|Количество уникальных заказов — `COUNT(DISTINCT order_id)`|
|average_item_price|нет|Средняя цена товарной позиции — `AVG(price)`|

## 5. Измерения

|Dim|Ключ|Важные атрибуты|SCD1 / SCD2 / нет|
|---|---|---|---|
|dim_product|product_id|Категория товара, вес, размеры, количество фотографий|SCD1|
|dim_customer|customer_id|Уникальный ID покупателя, город, штат, почтовый индекс|SCD1|
|dim_seller|seller_id|Город, штат, почтовый индекс|SCD1|
|dim_date|date_key|Дата, день, месяц, квартал, год|Нет|

## 6. Три бизнес-вопроса

1. Какой оборот по штатам покупателей за каждый месяц?
    
2. Какие категории товаров приносят наибольший оборот?
    
3. Какие продавцы имеют наибольшее количество проданных товарных позиций?
    

## 7. Эталонный SQL одной метрики (черновик → уточнить на P04)

```
-- Главная метрика: оборот по доставленным товарам без стоимости доставки

SELECT
    SUM(oi.price) AS revenue
FROM olist_order_items_dataset AS oi
JOIN olist_orders_dataset AS o
    ON oi.order_id = o.order_id
WHERE o.order_status = 'delivered';
```

## 8. Риски / cut

В рамках проекта не реализуются:

- Обработка возвратов и возмещений: метрика оборота не будет учитывать отдельные возвраты и компенсации.
    
- Прогнозирование продаж и машинное обучение: проект ограничивается анализом исторических данных.
    
- Обработка данных в реальном времени: используются заранее загруженные CSV-файлы.
    
- Развёртывание распределённого кластера ClickHouse: используется локальный учебный стенд.
