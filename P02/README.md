
## Схема «звезда»

В центре — таблица фактов `fact_order_items` (товарные позиции заказов). Вокруг — 4 справочника `dim_*`.

**Одна строка в** `**fact_order_items**` **= одна позиция товара в заказе** (ключ: `order_id` + `order_item_id`).

### Таблицы

|**Таблица**|**Что внутри**|
|---|---|
|`fact_order_items`|Товарные позиции заказов: товар, покупатель, продавец, дата покупки, цена и стоимость доставки|
|`dim_product`|Товары (категория, вес, размеры, количество фотографий)|
|`dim_customer`|Покупатели (уникальный ID, город, штат, почтовый индекс)|
|`dim_seller`|Продавцы (город, штат, почтовый индекс)|
|`dim_date`|Календарь (день, месяц, квартал, год)|

### Как связаны

Факт ссылается на справочники по ключам:

|**В факте**|**Куда ведёт**|
|---|---|
|`product_id`|`dim_product.product_id`|
|`customer_id`|`dim_customer.customer_id`|
|`seller_id`|`dim_seller.seller_id`|
|`date_key`|`dim_date.date_key` (по дате покупки заказа)|

Данные о покупателе и дате покупки поступают из `olist_orders_dataset.csv` через связь по `order_id`.

### Метрики (что считаем)

- `revenue` — оборот по стоимости товаров без доставки (`SUM(price)`) для доставленных заказов.
    
- `freight_total` — общая стоимость доставки (`SUM(freight_value`)).
    
- `order_items_count` — количество товарных позиций (`COUNT(*)`).
    
- `orders_count` — количество уникальных заказов (`COUNT(DISTINCT order_id)`).
    
- `average_item_price` — средняя цена товарной позиции (`AVG(price)`).
    

### Главная метрика

**Оборот по доставленным товарам без стоимости доставки.**

Черновая формула: сумма `price` для товарных позиций заказов со статусом `delivered`.

### Исходные данные

В проекте используются 9 исходных CSV-файлов из Brazilian E-Commerce Public Dataset by Olist.

|**Исходный файл**|**Назначение**|
|---|---|
|`olist_order_items_dataset.csv`|Основной источник товарных позиций для таблицы фактов|
|`olist_orders_dataset.csv`|Даты покупки, статусы заказов и связь с покупателями|
|`olist_customers_dataset.csv`|Данные покупателей|
|`olist_products_dataset.csv`|Данные товаров и категории|
|`olist_sellers_dataset.csv`|Данные продавцов|
|`olist_order_payments_dataset.csv`|Данные об оплатах; пока не включены в основную модель|
|`olist_order_reviews_dataset.csv`|Отзывы покупателей; пока не включены в основную модель|
|`olist_geolocation_dataset.csv`|Географические координаты; отдельное измерение пока не создаётся|
|`product_category_name_translation.csv`|Перевод названий категорий товаров на английский язык|

Не каждый исходный CSV становится отдельной таблицей витрины. Некоторые файлы используются для обогащения данных, остальные пока не входят в основную модель.

### История справочников

|**Справочник**|**Стратегия**|
|---|---|
|`dim_product`|SCD1 — обновляем старые значения|
|`dim_customer`|SCD1 — обновляем старые значения|
|`dim_seller`|SCD1 — обновляем старые значения|
|`dim_date`|Нет — календарные данные не изменяются|

### Ограничения проекта

- Возвраты и возмещения отдельно не анализируются.
    
- Прогнозирование продаж и машинное обучение не реализуются.
    
- Обработка данных в реальном времени не реализуется.
    
- Распределённый кластер ClickHouse не разворачивается.
    
- История изменений справочников SCD2 не реализуется.
