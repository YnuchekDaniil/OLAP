# P04. Аналитический SQL

## Структура

```text
OLAP/
└── P04/
    ├── sql/
    │   ├── canonical_metric.sql   # эталон главной метрики (revenue)
    │   └── analytics.sql          # ответы на 3 бизнес-вопроса из паспорта
    ├── scripts/
    │   └── run_sql.py             # выполнение SQL-файлов в DuckDB (P03/olist_dw.duckdb)
    ├── passport.md                # обновлённый паспорт с эталонным SQL метрики
    ├── results.txt                # сохранённый вывод запросов
    └── README.md
```

## Соответствие вопросов и запросов

| Вопрос из паспорта | Запрос в `sql/analytics.sql` | Оконная функция |
|--------------------|------------------------------|-----------------|
| 1. Какой оборот по штатам покупателей за каждый месяц? | Запрос 1 | `SUM(revenue) OVER (PARTITION BY year, month)` (доля штата в обороте месяца) |
| 2. Какие категории товаров приносят наибольший оборот? | Запрос 2 | `RANK() OVER (ORDER BY revenue DESC)`, `SUM(revenue) OVER ()` (рейтинг и доля в общем обороте) |
| 3. Какие продавцы имеют наибольшее количество проданных товарных позиций? | Запрос 3 | `RANK() OVER (ORDER BY order_items_count DESC, revenue DESC)` (рейтинг продавцов) |

## Как запустить

Из корневой папки проекта `OLAP`:
```bash
python P04/scripts/run_sql.py
```

Сохранить вывод в файл `P04/results.txt`:
```bash
python P04/scripts/run_sql.py > P04/results.txt
```
